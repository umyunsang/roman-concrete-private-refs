## 3. 권장 파이프라인

'Blender가 구조, AI가 표면(Blender truth, AI skin)' 하이브리드 파이프라인이다. 상업적으로 안전한 Apache/MIT 가중치만 쓴다.

### 0단계. 라이선스 관문

- 허용: Z-Image / Z-Image-Turbo, Qwen-Image-2512, Qwen-Image-Edit-2511, alibaba-pai / InstantX / DiffSynth ControlNet, FLUX.2 klein 4B, SeedVR2, HiDream-O1(MIT).
- 금지: Qwen-Image-2.1(연구용 라이선스, **비상업**), 모든 Hunyuan(**한국 지역 제외**), FLUX dev / Kontext / Redux / FLUX.2 dev / klein 9B(**비상업 라이선스**).
- 조건부: FLUX 3 Klein(매출 US$5M 미만만), Krea 2와 SD3.5(US$1M 미만).

### 1단계. 블록아웃 (Blender MCP, 랜드마크당 약 1-3시간)

- 공유 리그 하나를 만든다. 고도 35.264도·방위 -45도의 직교 카메라, 공유 태양 방향, 같은 팔각 흙 절단 받침 메시로 구성한다.
- 사실이 맞아야 하는 것만 모델링한다: 아케이드 오더와 베이 수, 링 벽, hypogeum, 기초 절개, 돔 셸 두께와 오큘러스, 수도교 specus 단면, 포르투스 육각형 내항, 균열 치유 단면, 사람 크기 프록시.
- 렌더 출력: 클레이 패스(AO 포함), depth 패스(가까울수록 흰색), canny/Freestyle 선, 재질 ID 마스크.
- 작동하는 예시: `pantheon_blockout.py`

### 2단계. 1-2 MP로 생성

- 기본: Z-Image-Turbo + Fun ControlNet Union 2.1(depth 0.7-0.9 + canny 0.4-0.6, 약 20 steps), 고정 스타일 블록, 선택적으로 ISOMETRIC-REDMOND 0.3-0.5.
- 대안: Qwen-Image-Edit-2511에 [클레이 렌더, 승인된 스타일 앵커]를 넣고 'render image 1 in the style of image 2, keep geometry'로 프롬프트한다.
- 랜드마크당 시드 20-40개를 돌린다.

### 3단계. 밀도 보강과 수정

- 재질 ID 영역별로 마스크 인페인팅(Z-Image 또는 Qwen-Edit-2511)을 해서 작업자, hot-mixing 구덩이, 노점, 암포라, 풀을 더한다.
- 블록아웃과 대조해 아치 수를 고친다.
- FLUX 3 Klein 바운딩 박스는 사용자가 그 라이선스 자격을 갖출 때만 선택적으로 쓴다.

### 4단계. 일관성 고정

- 히어로 3-5개가 승인되면 우리 크롭으로 rank-8~16 스타일 LoRA를 학습한다(대여 GPU에서 ai-toolkit, 또는 mflux-train).
- 그 LoRA로 나머지 랜드마크를 다시 생성한다.

### 5단계. 업스케일

- Z-Image Tile ControlNet + Ultimate SD Upscale(denoise 0.2-0.35), 또는 SeedVR2로 디오라마당 약 4-6k px까지 올린다.
- Blender 알파나 마스크로 매트를 딴다.

### 6단계. 합성

- 모든 한국어 타이포그래피, 지시선, 차트, 타이틀 락업은 4961x7016 크기의 Figma/SVG 203X 레이아웃에 넣는다.
- 'illustrations generated with AI (Z-Image, Apache-2.0) from original 3D blockouts' 같은 작은 크레딧 라인을 넣는다.

### 실행 위치

- Blender와 레이아웃은 M1에서 로컬로 돌린다.
- 생성은 Comfy Cloud에서 한다(**유료** 크레딧: 먼저 estimate_credits를 호출하고 사용자 승인을 받는다).
- 또는 디스크를 최소 15-30 GB 비운 뒤에만 mflux로 Z-Image-Turbo 4-bit를 **M1 로컬**에서 돌린다.
