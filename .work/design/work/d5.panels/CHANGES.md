## 2. 통합 수정(통합 담당)

### 2.1 render ↔ map: 랜드마크 평면 원본 열쇠 불일치 (1회차 렌더 중단의 원인)
- 원인: 두 워커가 같은 `plan`에 서로 다른 열쇠 구조를 썼다.
  - map은 중첩 열쇠를 썼다: L7 `paving{rects_plan [X0,X1,Y0,Y1]}`·`aisle{X,Y,h,bays}`·`nave_ruins`·`nave_vault_dashed`, L8 `base{X,Y,h}`·`drum{c,r,z}`·`top{parapet,mound}`·`bridge{deck_X,deck_Y}`, L9 `plan{c,r}`·`arcade{h,tier_h}`·`stage_wall`.
  - render는 평면 열쇠(`base_rects`·`aisle`·`drum_c` …)를 읽었다.
  - 그래서 `aisle`이 사전이라 `float('name')`에서 멈췄다.
- 수정(`render.py`): `_flat_plan()`을 더했다. map 중첩 열쇠를 render 평면 열쇠로 옮긴다.
  - 사각형 순서 [X0,X1,Y0,Y1] → [X0,Y0,X1,Y1]도 바로잡는다.
  - 점선 복원 높이는 지면 기준 ≤ 10이 되게 포장 위 8.5로 둔다.
  - 영묘 둔덕 반지름은 사양 `mound.r_max` 10을 쓴다.
  - 결과: L7 신랑 앞 끝 X 335.5, L8 사양 좌표, L9 반원이 사양 그대로 그려진다.
- 네로 거상: map의 `pedestal{plan_size,h}`·`statue{plan_size,z}`를 읽게 했다. 값은 결정과 같아 그림은 그대로다.

### 2.2 render ↔ panels: P2·P5 인쇄 글 불일치
- 원인: render는 `print` 열쇠만 읽었다. 그런데 panels는 `head`·`cells`·`cell_text`·`span_bars.rows`·`footnote`(P2)와 `stairs`·`cells`·`carbon`(P5)로 적었다. 그래서 render의 대체 문안이 인쇄됐다.
  - 예: '아치를 한 바퀴 돌린 둥근 지붕', 탄소 문장의 '현대 콘크리트와' 누락.
- 수정(`render.py`): `_p2_print()`·`_p5_print()`로 panels 사양 글을 그대로 쓴다.
  - P2 칸은 사양 배치를 따른다: 그림(figure_box, 짝 표지 원과 1mm 띄워 y 36.5부터) → 이름 기준선 52.2 → 캡션 55.6·58.6.
  - 스팬 막대는 사양 막대 자리(y 66·72.5·79)를, 각주는 기준선 90.6을 쓴다.
  - P5 두 칸 제목 앞에 사양 아이콘 ○(가져올 것)·×(못 가져올 것)를 그린다.

### 2.3 render ↔ panels: 라벨 슬롯 열쇠
- 수정(`render.py`): 슬롯을 읽은 뒤 다음처럼 옮긴다.
  - `top_edge{d|c, x}` → `top_line`·`x_range`
  - `flag{x}` → `pole_x`(화산재 운반선 깃대 x 144.25 고정)
  - 소품 주석의 `tag_text` → `lines`
- 고치기 전에는 네로 거상 주석이 빈 글이 될 뻔했다. 주석 글꼴은 사양 `font`('m', panels 실측 기준)를 따른다.

## 5. 미해결(기획 판정 또는 다음 회차)
- 네로 거상 주석 지시선은 14.7mm다(결정 ≤ 12mm). 슬롯 오른쪽 변 x 172와 거상 머리 x ≈ 184가 가로 13mm라 ↘30° 한 직선으로는 닿지 않는다. ≤ 12mm로 하려면 슬롯을 x 174.6 이상으로 넓혀야 한다. 그러면 바실리카 왼쪽 꼭짓점에 3mm까지 다가간다(panels 기록).
- 영묘 지시선 끝은 (141.49,424.71)이다. 결정 대상점 (140.5,421)은 블록 왼쪽 끝 ↖30° 직선에 오지 않는다. panels 사양은 (138.0,423.8)로 옮겼고, render는 기단 윗면 띠의 가장 가까운 점에 닿는다(간격 0).
- 화산재 운반선 깃대 위 끝은 y 479.72다(결정 478.0). 아래 끝 495.05는 결정과 같다.
- 결정값과 달라진 좌표가 있다. 사유는 모두 간격 2mm 확보다.
  - L7 신랑·포장 앞 끝: X 338 → 335.5(면적 4,663 → 4,566)
  - L8 원통 중심: (488,347.5) → map (489,347.8) → 통합 (489.6,348.4). 기단 44 → 45, 다리·R7 X 488 → 489.6.

- L8 정상: 사양은 테두리 난간 z 23~25.5 + 흙 둔덕 z 28이다. render는 난간을 z 23의 낮은 테 선으로 그리고 둔덕(반지름 10)만 z 28까지 올렸다.
- 원통 꼭대기–부두 간격: 기획의 '≥ 4mm'는 원통 중심 한 점 기준이다. 그린 실루엣으로는 2.2mm다(⑭ ≥ 2 통과). 4mm를 지키려면 영묘 자리나 높이를 다시 판정해야 한다.

  - 그림으로만 확인한 형태: 하이포게움 개구부·회랑, 수도교 관통 아치, 베수비오 앞 능선 연속 가림, P2 막대 비례·P5 계단
