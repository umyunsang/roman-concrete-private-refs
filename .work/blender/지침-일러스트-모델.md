# 워커 지침: Blender 일러스트 모델 제작
Opus 수정 워커용 지침이다. 시작 전에 반드시 기준선 `.work/blender/기준선-최종본.md`를 먼저 읽는다.

## 1. 작업 환경(사용자가 띄운 Blender 하나를 함께 쓴다)
- **도구**: `mcp__blender__execute_blender_code`로 Python을 보내고, `mcp__blender__look`으로 화면을 확인한다. 둘 다 ToolSearch로 불러온다.
  - 헤드리스 Blender(`blender -b`)를 따로 띄우지 않는다(사용자 지시).
- **장면**: `ROMA_MAP`, 파일 `.work/blender/roma_map.blend`. 저장은 통합 담당만 한다(`bpy.ops.wm.save_mainfile`). 워커는 저장하지 않는다.
- **모듈**: 원본은 `.work/blender/lib/*.py` 파일이다. 파일을 Read/Edit/Write로 고친 뒤 Blender에서 다시 불러온다.
  ```python
  import roma_load; M = roma_load.load_all(extra=('roma_render',))   # 공용 모듈
  pk = roma_load.load('roma_pkg_city')                               # 내 패키지 모듈
  pk.build()                                                          # 내 컬렉션만 지우고 다시 짓는다
  ```
  - `roma_load.load_all()`이 불러오는 공용 모듈: roma_kit, roma_flat, roma_geo, roma_props, roma_layers, roma_colo, roma_colo_in. 담당은 bglobal이다(설계 패키지 global과 다르다).
- 여러 워커가 같은 Blender에 번갈아 명령을 보낸다. 지켜야 할 것:
  - 명령 하나는 90초 안에 끝나게 짠다.
  - 다른 패키지의 컬렉션·오브젝트·재질·파일은 건드리지 않는다.
- **금지**:
  - 장면 설정(카메라 `CAM_ISO`·렌더 엔진·색 관리·월드)을 바꾸지 않는다. 예외: `render_region`이 렌더하는 동안 잠깐 바꿨다 되돌리는 것.
  - 조명·해·AO·그림자를 쓰지 않는다. Principled BSDF·실사 텍스처도 쓰지 않는다.
  - 파일을 지우지 않는다.

## 2. 좌표·크기
- 설계 평면 (X, Y)에서 Y는 아래로 간다. Blender 월드 좌표는 `roma_kit.P(X, Y, Z) = (X, −Y, Z)`이고, 1 BU = 평면 1 mm다.
- 화면 mm 변환:
  - 평면 → 화면: `roma_kit.to_screen(X, Y, Z)`
  - 화면 → 평면: `roma_kit.to_plan(x, y)` (Z=0 기준)
  - 월드 점 → 화면 mm: `roma_kit.scr(vector)`
- **땅 윗면은 Z = 0이다.** 모든 건물은 Z=0에 세운다. 콜로세움도 받침 없이 그대로 선다(사용자 06:06).
- 땅을 파야 하면(구덩이·물길) 숨긴 절단체 `X_CUT_{이름}`을 내 컬렉션에 둔다. ground가 땅 판을 지을 때 모든 `X_CUT_*`로 파낸다. 그래서 통합 담당은 ground를 맨 마지막에 다시 짓는다.
- **투영 상자 맞추기**: 건물을 지역 좌표로 지은 뒤 `roma_geo.fit_to_box(root, box_mm)`를 쓴다. 균일 축척과 평면 이동으로 화면 외곽을 spec 투영 상자에 맞추며, 지면 Z는 그대로 둔다.
- spec: `.work/design/current/out/spec.json` `core_map`. 쓰는 항목:
  - landmarks[].projected_box·form
  - river.polygon_screen
  - sea_coast, portus_geometry, roads[].plan_pts·w_screen_perp_mm
  - aqueduct, props, terrain, planted
- 보이는 면: 카메라는 평면 앞쪽(방위 45°)에서 본다. 보이는 면은 다음 셋이다.
  - 윗면
  - 왼면: 법선이 Blender −Y 쪽
  - 오른면: 법선이 Blender +X 쪽
  - 뒤쪽 벽은 안쪽 면이 보인다.

## 3. 재질(벡터 일러스트)
- `roma_flat.flat(이름, '#RRGGBB')`: 평면색. 방출 셰이더에 `ISO_TONE` 면 방향 톤만 곱한다.
- `roma_flat.blocks(이름, c1, c2, c3, 줄눈색, 블록폭, 줄높이, 줄눈폭)`: 경계가 또렷한 블록 무늬. UV는 mm 단위다(`roma_geo` 도형은 UV를 자동으로 만든다).
- 팔레트 `roma_flat.PAL`:
  - 트래버틴: trav·trav_hi·trav_lo·trav_deep·trav_deeper
  - 벽돌: brick·brick_hi
  - 그 밖: 응회암, 흙, 판석, 풀, 사이프러스·올리브, 천, 피부 …
  - 새 색은 이름에 패키지 접두사를 붙인다(예: `F_city_marble`).
- 색은 LocalBanana의 따뜻한 미니어처 색감을 203X식 평면색으로 옮긴다. 회색·검정 덩어리는 피한다.
- 깊이(개구부 속·회랑·처마 밑)는 짙은 평면색으로 칠한다(L1). 빛을 계산하지 않는다.

## 4. 오브젝트 하나 = 표현 레이어 여러 겹(필수)
- 이름 규칙: `{PKG}_{Obj}_L{n}_{part}` (예: `CITY_Pantheon_L3_Masonry`).
- 오브젝트마다 루트 Empty `{PKG}_{Obj}_root` 아래에 둔다.

| 층 | 내용 | 예(판테온) |
|---|---|---|
| L0 덩어리 | 볼륨·면 톤 | 원통·돔·주랑 현관·박공 |
| L1 깊이색 | 개구부·그늘진 안쪽을 짙은 평면색으로 | 현관 안, 기둥 사이 어둠, 문, 오큘러스 속 |
| L2 부재 | 기둥·띠·코니스·문틀·계단 | 화강암 기둥 16개, 주두, 엔타블러처, 돔 계단 고리 3단 |
| L3 표면 무늬 | 블록·벽돌·기와·판석·잎결 | 원통의 벽돌 띠·막힌 아치, 돔 납판 줄, 박공 기와 |
| L4 형태 디테일 | 창·문·조각·파손·잔해 | 비문 띠, 청동 문, 벽감, 박공 부조 자리 |
| L5 하이라이트 | 윗선·모서리 밝은 띠(가는 면) | 코니스 윗선, 기둥 밝은 쪽 띠, 돔 고리 윗선 |
| L6 얼룩·식생·생활 | 빗물 자국·이끼·풀·사람·소품 | 광장 사람·노점·나무, 돔 위 얼룩 |
| L7 외곽선(선택) | 공용 선(global) | — |

- 콜로세움(hero)의 L0~L4는 이미 있다: `H_L0_*`, `H_L2_Orders`, `H_L4_RuinBlocks`. 이 위에 L5·L6를 쌓는다. 둘레는 LocalBanana 조경을 복제하지 않고(12:49 철회) 승인 설계의 히어로 군(광장·공사장·인물 무리·네로 받침·문·시내 지붕과 나무)으로 짓는다. 팔각 받침은 없다.
- 사람·나무·노점·암포라·수레·배 원형은 `roma_props`에 있다(`place()`). 다만 색을 평면 재질로 바꾸거나 더 자세한 원형이 필요하면 bglobal에 요청한다.

## 7. 통합 루프(12:18)
- 위치·크기의 원천은 설계판 spec(`.work/design/current/out/spec.json`)이다. 하드코딩한 좌표가 spec과 어긋나면 spec을 따른다.

- 같은 회차에 설계 워커가 spec을 고치는 중일 수 있다. 기획자의 공통 결정(decisions)에 적힌 mm 수치를 우선한다.
